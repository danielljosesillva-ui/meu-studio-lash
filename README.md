MEU STUDIO LASH - versão instalável (PWA)

1) Hospede esta pasta em um site com HTTPS (obrigatório para instalar):
   - Netlify: acesse app.netlify.com/drop e arraste a PASTA "pwa" (ou o ZIP).
   - ou GitHub Pages / Cloudflare Pages / Vercel.
2) Abra o endereço no celular.
   - Android (Chrome): menu ⋮ > "Instalar app" / "Adicionar à tela inicial".
   - iPhone (Safari): Compartilhar > "Adicionar à Tela de Início".
3) Os dados ficam só no aparelho. Use Ajustes > Backup > Exportar com frequência.
